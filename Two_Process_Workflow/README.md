# Two-Process Nextflow Workflow

## Objective
Demonstrate how two Nextflow processes can be connected into a workflow.

## Script
`two-process-workflow.nf`

## Workflow
1. `CREATE_GREETING` creates a file containing `Hello Nextflow`.
2. `ADD_CONTEXT` receives the first process's output and creates the final result.

## Execution
Command:

`nextflow run Two_Process_Workflow/two-process-workflow.nf`

## Verification
Both processes completed successfully.

The final output in `evidence/final.txt` is:

    Two-process workflow result:
    Hello Nextflow

## Evidence
- `evidence/two-process-workflow-run.log` — execution log.
- `evidence/final.txt` — output generated by the workflow.

## Learning outcome
Nextflow processes can pass output files to downstream processes, allowing workflows to be organized into reusable steps.
