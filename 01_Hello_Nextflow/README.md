# Hello Nextflow — Official Training

## Overview
This directory contains evidence from completing the six core sections of the official Hello Nextflow training.

## Sections
1. [Hello World](01_Hello_World/README.md)
2. [Channels](02_Channels/README.md)
3. [Workflow](03_Workflow/README.md)
4. [Modules](04_Modules/README.md)

## Evidence
Each section contains its exercise script, a README describing the work, and an evidence directory containing execution logs where applicable.

## Learning outcomes
- Basic Nextflow process execution
- Channel creation and data flow
- Workflow organization
- Reusable processes and modules
- Container-based execution
- Workflow configuration

## Environment
Nextflow 26.04.4 was used for the recorded runs. The terminal also displayed an informational notice about a newer version being available.
