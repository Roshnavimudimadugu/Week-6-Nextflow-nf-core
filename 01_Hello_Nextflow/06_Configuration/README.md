# Hello Nextflow — Configuration

Official training: https://training.nextflow.io/latest/hello_nextflow/06_hello_config/

## Objective
Explore how Nextflow configuration influences workflow execution and process behavior.

The `sayHello`, `convertToUpper`, `collectGreetings`, and `cowpy` processes completed successfully.
