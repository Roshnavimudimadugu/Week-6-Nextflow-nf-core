# nf-core/rnaseq — Documentation Evidence

## Official resources
- Usage and samplesheet: https://nf-co.re/rnaseq/latest/docs/usage
- Pipeline outputs: https://nf-co.re/rnaseq/latest/docs/output

## Contents
- `samplesheet.csv`: illustrative samplesheet with placeholder FASTQ paths.
- `usage_and_samplesheet.md`: samplesheet columns and input handling.
- `parameters_profiles_reference_inputs.md`: parameters, profiles, and reference files.
- `output_summary.md`: quality-control, MultiQC, alignment, quantification, and reporting outputs.
- `evidence/`: reserved for relevant screenshots or documentation evidence.

## Learning outcomes
- Understand the required RNA-seq samplesheet structure.
- Recognize commonly used pipeline parameters and execution profiles.
- Understand genome FASTA and annotation inputs.
- Locate quality-control reports, alignment summaries, and gene/transcript quantification outputs.
- Understand that published output files depend on pipeline options and analysis choices.

## Scope
This is a documentation exercise. The sample FASTQ paths are placeholders; a full nf-core/rnaseq analysis has not been run for this section.
